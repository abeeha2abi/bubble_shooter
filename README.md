# 🫧 Bubble Shooter Game

A fun, colorful, and interactive **Bubble Shooter game** built with **Python and Pygame**. Aim, shoot, and match bubbles to clear the board and earn points!

## 🎮 Features

* 🎯 Smooth bubble aiming and shooting
* 🫧 Color-based bubble matching
* 💥 Bubble popping effects
* ⭐ Score system
* 🎮 Interactive gameplay
* 🏆 Win and game-over conditions
* 🔄 Restart/replay functionality
* 🎨 Colorful and user-friendly interface
* ⚡ Smooth gameplay using Pygame

## 🛠️ Technologies Used

* **Python 3.14**
* **Pygame / pygame-ce**
* Object-oriented and event-driven game logic

## 🚀 How to Run

### 1. Install Python

Make sure Python is installed on your computer.

### 2. Install Pygame

Open the terminal and run:

```bash
pip install pygame-ce
```

### 3. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/bubble-shooter.git
```

### 4. Open the Project

```bash
cd bubble-shooter
```

### 5. Run the Game

```bash
python bubble_shooter.py
```

## 🕹️ Controls

| Key / Action       | Function         |
| ------------------ | ---------------- |
| 🖱️ Mouse Movement | Aim the bubble   |
| 🖱️ Left Click     | Shoot bubble     |
| 🔄 Restart Button  | Restart the game |
| ❌ Close Window     | Exit the game    |

## 🎯 How to Play

1. Aim the shooter toward the bubbles.
2. Click to shoot a bubble.
3. Match bubbles of the same color.
4. Pop matching bubbles to earn points.
5. Clear the required bubbles to progress.
6. Avoid letting the bubbles reach the bottom.
7. Try to achieve the highest score! 🏆
